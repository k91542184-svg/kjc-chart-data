# KJC 차트 데이터 파이프라인

김종철 판독 차트에 미국주식 일봉 데이터를 **무료로, 매일 자동으로** 공급하는 저장소입니다.
API 키가 필요 없습니다. GitHub Actions 러너에서 `yfinance`로 받아 JSON으로 커밋합니다.

---

## 설치 — 세 단계, 한 번만 하면 됩니다

### 1단계 · 공개 레포 만들기

GitHub에서 새 레포를 만듭니다.

| 항목 | 값 |
|---|---|
| 이름 | `kjc-chart-data` (원하는 이름으로 바꿔도 됩니다) |
| 공개 설정 | **Public** ← 반드시 공개여야 합니다 |
| README | 체크하지 않아도 됩니다 |

> **왜 공개여야 하나요?** 비공개 레포의 파일은 토큰이 있어야 읽을 수 있는데,
> 데이터를 받아가는 쪽에는 그 토큰이 없습니다. 담기는 건 공개 시세 데이터뿐이라
> 민감한 내용이 없습니다. 알림 시스템 레포(`us-stock-new`)는 비공개로 두셔도 됩니다.

### 2단계 · 파일 넣기

이 폴더의 파일을 그대로 레포에 올립니다. 구조는 이렇습니다.

```
kjc-chart-data/
├─ .github/workflows/kjc-data.yml    ← 매일 자동 실행
├─ scripts/build_kjc_data.py         ← 수집 스크립트
├─ tickers.txt                       ← 수집할 종목 (여기만 고치면 됩니다)
└─ data/                             ← 결과가 쌓이는 곳 (자동 생성)
```

`data/` 폴더는 비어 있어도 됩니다. 첫 실행 때 만들어집니다.

### 3단계 · 한 번 돌려보기

레포의 **Actions** 탭 → 왼쪽에서 **KJC 차트 데이터 수집** 선택 → 오른쪽 **Run workflow** 버튼.

2~5분 뒤 `data/` 폴더에 `NVDA.json` 같은 파일과 `index.json`이 생기면 성공입니다.

그 다음 **레포 주소를 알려주세요.** 나머지는 이쪽에서 연결합니다.

## 동작 방식

```
매일 23:00 UTC (미국 정규장 마감 후)
   │
   ├─ tickers.txt 를 읽는다
   ├─ 종목마다 yfinance 로 6년치 일봉을 받는다  ← 실패하면 3회까지 재시도
   ├─ data/<TICKER>.json 로 저장
   ├─ data/index.json 에 갱신 시각·종목별 요약 기록
   └─ 변경분만 커밋 (변경 없으면 커밋하지 않음)
```

**6년치인 이유**는 김종철 기준선을 전부 계산하기 위한 최소 길이이기 때문입니다.

| 기준선 | 필요한 기간 |
|---|---|
| 일봉 240선 | 1년 |
| 주봉 240선 | 4.6년 |
| **월봉 72선** | **6년** ← 가장 긴 요건 |

## 데이터 형식

`data/NVDA.json`

```json
{
  "ticker": "NVDA",
  "updated": "2026-09-07T23:04:11Z",
  "source": "yfinance (Yahoo Finance) · 액면분할 반영 · 배당 미반영",
  "fields": ["t","o","h","l","c","v"],
  "rows": [
    ["2020-09-08", 128.55, 131.2, 125.9, 126.14, 51234000],
    ["2020-09-09", 127.0, 133.4, 126.8, 132.75, 48910000]
  ]
}
```

`data/index.json`

```json
{
  "updated": "2026-09-07T23:04:11Z",
  "period": "6y",
  "count": 17,
  "failed": [],
  "tickers": [
    { "t": "AMD", "n": 1509, "from": "2020-09-08", "to": "2026-09-04", "last": 168.22 }
  ]
}
```

`failed` 배열이 비어 있지 않으면 그 종목은 이번 회차에 못 받은 것입니다.
**기존 파일은 지우지 않으므로 이전 데이터가 그대로 남습니다.**

## 종목 바꾸기

`tickers.txt` 만 고치면 됩니다. 한 줄에 하나, `#` 뒤는 설명입니다.

```
NVDA
AMD      # 반도체
005930.KS   # 국내 종목도 이렇게 넣을 수 있습니다
```

다음 실행부터 반영됩니다. 바로 반영하고 싶으면 Actions에서 **Run workflow**를 누르세요.

## 알아두실 점

- **yfinance는 Yahoo의 비공식 경로입니다.** 무료지만 예고 없이 막힐 수 있습니다.
  `index.json`의 `failed` 목록이 계속 차면 그 신호이고, 그때는 무료 API 키 방식으로
  갈아타야 합니다. 스크립트의 `fetch()` 함수만 바꾸면 되도록 짜 두었습니다.
- **GitHub Actions 무료 사용량**: 공개 레포는 Actions가 무제한 무료입니다.
  이 작업은 하루 몇 분이라 비용이 발생하지 않습니다.
- **종목이 60개를 넘어가면** 종목당 1.2초 대기 때문에 실행이 길어집니다.
  그때는 말씀해 주시면 병렬 수집으로 바꿔 드리겠습니다.
- **장 마감 직후 데이터**는 정정될 수 있습니다. 다음 날 실행 때 자동으로 덮어씁니다.
